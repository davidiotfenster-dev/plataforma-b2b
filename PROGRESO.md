## 2026-09-28 — Frontend scaffold, primera demo y arranque de backlog de UX
- Entre sesiones (no documentado hasta ahora) se generó `/frontend` con `create-next-app` (Next.js 16.3.6, App Router, React 19, Tailwind v4, TanStack Query, Zustand) y se construyeron ya las pantallas principales: `login`, `registro`, `catalogo`, `carrito`, `checkout`, `pedidos` (+ detalle `pedidos/[id]`), `admin/partners`, `admin/pedidos`, junto con `lib/api.ts` (cliente fetch con cookies), `hooks/use-me.ts` y `components/navbar.tsx`. Backend y frontend corriendo en paralelo (backend `PORT=3010`, frontend `localhost:3004`), Postgres (`5433`) y Redis (`6379`) en Docker.
- **Bug encontrado y corregido — fondo negro/texto invisible en la home**: `frontend/src/app/globals.css` tenía una regla `body { background: var(--background); color: var(--foreground); }` **fuera de cualquier `@layer`**. En Tailwind v4, el CSS sin capa siempre gana sobre las utilidades (`bg-neutral-50`, etc.) independientemente de especificidad.
